Λιαστές ντομάτες, η παρασκευή της Αργυρώς

Κάθε χρόνο τον Αύγουστο που οι ντομάτες είναι στα καλύτερά τους, τις φτιάχνουμε λιαστές!

Από Αργυρώ Μπαρμπαρίγου

Υλικά

ΓΙΑ ΤΙΣ ΛΙΑΣΤΕΣ ΝΤΟΜΑΤΕΣ

  • Ντομάτες κατά προτίμηση άνυδρες Σαντορίνης
  • Αλάτι
  • Λάδι
  • Μυρωδικά (προαιρετικά)
  • Αποστειρωμένα βαζάκια
  • Τούλι ή άλλο λεπτό ύφασμα

Εκτέλεση

  1. Κόβετε τις ντομάτες στη μέση, τις βάζετε σε ένα ταψί με τη φλούδα τους να ακουμπάει στην επιφάνεια του ταψιού και τους ρίχνετε άφθονο αλάτι.
  2. Καλύπτετε το ταψί με ένα πολύ λεπτό ύφασμα, όπως τούλι ή γάζα και τις «ξεχνάτε» στον ήλιο για μερικές ημέρες, συνήθως 3-4, μέχρι να εξατμιστούν εντελώς τα υγρά τους, αλλά να μην γίνουν πολύ σκληρές. Το βράδυ, καλό είναι να τις βάζετε μέσα στο σπίτι, για να αποφύγετε τον κίνδυνο να τραβήξουν υγρασία.
  3. Όταν τις πιάνετε, και είναι σαν πετσί εύκαμπτο, είναι έτοιμες. Τότε, τις βάζετε σε αποστειρωμένο βαζάκι και καλύπτετε με λάδι.
  4. Σε αυτό το στάδιο, μπορείτε να προσθέσετε και κάποια μυρωδικά, όπως ρίγανη, θυμάρι, κόλιανδρο ή σκόρδο, και τις φυλάτε στο ντουλάπι. Προσοχή να τις καλύπτει πλήρως το λάδι.
  5. Η συνταγή για λιαστές ντομάτες είναι τόσο εύκολη που όλοι θα δοκιμάσετε να την φτιάξετε και θα πετύχει σίγουρα!

ΣΗΜΕΙΩΣΗ

  1. Αν το σημείο που τις αποξηραίνετε είναι πολύ ηλιόλουστο, ή τις ξεχάσετε περισσότερες ημέρες με αποτέλεσμα να στεγνώσουν παραπάνω, δεν χρειάζεται να τις πετάξετε. Μπορείτε να τις περάσετε σε κλωστή και να τις κρεμάσετε μέσα στην κουζίνα σας, μακριά από ατμούς και υγρασίες, έτσι θα έχετε μια όμορφη διακοσμητική γιρλάντα από αποξηραμένες ντομάτες, ενώ όταν θέλετε να τις χρησιμοποιήσετε, απλά θα τις μουλιάζετε σε ζεστό νερό.
