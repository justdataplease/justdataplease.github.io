Η απίστευτη συνταγή του Βασίλη Καλλίδη για πατάτες φούρνου

Ακολουθήστε πιστά τις οδηγίες του σεφ Βασίλη Καλλίδη και θα βγουν λουκούμι οι πατάτες φούρνου. Το μόνο που μπορείτε να προσθέσετε αν θέλετε είναι πάπρικα καπνιστή, σκόρδο ή ρίγανη.

Από Γαστρονόμος

Υλικά

  • 3 κιλά πατάτες, καθαρισμένες
  • 1/2 φλιτζ. τσαγιού ελαιόλαδο
  • αλάτι

Εκτέλεση

  1. Για να φτιάξουμε τις πατάτες φούρνου, ξεκινάμε προθερμαίνοντας τον φούρνο στους 200°C.
  2. Κόβουμε τις πατάτες στα τέσσερα, όσο μεγάλες κι αν είναι.
  3. Στρώνουμε αντικολλητικό χαρτί σε ένα μεγάλο ταψί και απλώνουμε τις πατάτες.
  4. Τις αλατίζουμε, περιχύνουμε με το ελαιόλαδο και ανακατεύουμε καλά με τα χέρια μας.
  5. Απλώνουμε ξανά τις πατάτες φούρνου και τις ψήνουμε για περίπου 2 ώρες, μέχρι να γίνουν ιδιαίτερα τραγανές εξωτερικά, ενώ μέσα θα είναι μαλακές σαν πουρές! Στο ενδιάμεσο, τις γυρίζουμε μια δυο φορές για να ροδίσουν ομοιόμορφα.
