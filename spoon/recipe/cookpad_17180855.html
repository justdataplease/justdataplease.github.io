Συνταγή για πιπεριές τουρσί C&G

Το τουρσί πιπεριών είναι μια από τις πιο δημοφιλείς και παραδοσιακές μεθόδους διατήρησης της συγκομιδής πιπεριών τσίλι. Οι πιπεριές τουρσί οποιουδήποτε τύπου είναι μια ευπρόσδεκτη προσθήκη σε πολλά γεύματα. Προσθέτουν μια αλμυρή, πικάντικη γεύση σε σάντουιτς, γαρνιτούρες πίτσας, σαλάτες, ακόμη και σνακ. Απλά τις αγαπάμε. Αν είστε σαν εμένα, καταλήγετε με έναν τεράστιο αριθμό πιπεριών τσίλι που συγκομίζονται ταυτόχρονα και το τουρσί είναι ένας ιδανικός τρόπος για να τις διατηρήσετε. Καταψύχουμε πολλές πιπεριές, φτιάχνουμε επίσης πολλές και καυτερές σάλτσες, τις μαγειρεύουμε σε σούπες, τις…

Υλικά

  • Πιπεριές τσίλι. Μπορείτε να χρησιμοποιήσετε οποιοδήποτε είδος πιπεριάς με αυτή τη συνταγή. Η ποσότητα θα ποικίλει ανάλογα με το πώς τις κόβετε
  • Ξύδι. Συνήθως χρησιμοποιούμε λευκό ξύδι, αν και άλλα ξύδια προσφέρονται για τουρσιά, όπως το μηλόξυδο
  • Σκόρδο. Για επιπλέον γεύση
  • Μαύρα πιπέρια. Μπορείτε να χρησιμοποιήσετε πολλά άλλα καρυκεύματα. Δείτε παρακάτω
  • Αλάτι θαλάσσης
  • Ζάχαρη. Προαιρετικά, για μια πινελιά γλυκού

ΣΥΜΒΟΥΛΈΣ & ΣΗΜΕΙΏΣΕΙΣ ΣΥΝΤΑΓΉΣ:

  • Χρησιμοποιήστε οποιοδήποτε είδος πιπεριάς. Αυτή η συνταγή λειτουργεί με κάθε είδους πιπεριές τσίλι. Μπορείτε να φτιάξετε το τουρσί με γλυκές ή καυτερές πιπεριές μέχρι και υπερκαυτερές πιπεριές τσίλι
  • Επιλέξτε φρέσκες, ώριμες πιπεριές. Αποφύγετε τυχόν πιπεριές που έχουν αρχίσει να μαλακώνουν πάρα πολύ ή παρουσιάζουν σημάδια σήψης ή ασθένειας. Το φρέσκο είναι καλύτερο

ΣΥΝΤΗΡΗΣΗ:

  • Αποθηκεύστε τις πιπεριές τουρσί σας στο ψυγείο για πολλούς μήνες. Η διαδικασία του παστώματος ουσιαστικά διατηρεί
  • Μπορείτε να αποθηκεύσετε τα βάζα σε δροσερό, σκοτεινό μέρος. Θα χρειαστεί να αποστειρώσετε τα βάζα για να διατηρηθούν στο ράφι. Με αυτόν τον τρόπο μπορούν να διαρκέσουν για χρόνια
  • Ωστόσο, μόλις τα ανοίξετε, θα πρέπει να τα βάλετε στο ψυγείο

Χρησιμοποιώντασ πιπεριές τουρσί:

  • Μπορείτε να τις κόψετε και να τις ανακατέψετε σε σούπες ή μαγειρευτά, να τις χρησιμοποιήσετε ως καρύκευμα σε σάντουιτς, ή να τις ψήσετε σε πίτσες
  • Προτιμώ να φτιάχνω τουρσί με μια ποικιλία πιπεριών τσίλι, αν και μπορείτε να χρησιμοποιήσετε μόνο ένα είδος πιπεριάς σε κάθε βάζο

Εκτέλεση

  1. Πλένουμε και στεγνώνουμε τις πιπεριές μας. Πάντα φροντίστε να πλένετε και να στεγνώνετε τις πιπεριές τσίλι σας πριν τις χρησιμοποιήσετε. Επίσης, αποστειρώστε τυχόν βάζα και καπάκια βάζων σε βραστό νερό πριν τα χρησιμοποιήσετε.
  2. Φέρτε σε βράση μια κατσαρόλα με νερό και βράστε τα για μισή ώρα ή πλύνετε καλά με απορρυπαντικό πιάτων, ξεπλύνετε καλά και αποστειρώστε τα στον φούρνο μικροκυμάτων για 30-45 δευτερόλεπτα και βάλτε τα ανάποδα πάνω σε απορροφητικό χαρτί κουζίνας. Είναι έτοιμα για χρήση.
  3. Απλή άλμη. Τα βασικά βήματα για την παρασκευή πιπεριών τουρσί περιλαμβάνουν το κόψιμο των πιπεριών σας και στη συνέχεια τη βράση ενός καρυκευμένου διαλύματος άλμης. Η άλμη αποτελείται από ξύδι και αλάτι.
  4. Μπαχαρικά για τουρσιά. Από εκεί, θα προσθέσετε τα δικά σας μπαχαρικά στο τουρσί, τα οποία μπορείτε να χρησιμοποιήσετε χοντροκομμένα ή ολόκληρα.
  5. Τα τυπικά μπαχαρικά τουρσί περιλαμβάνουν αλάτι και ζάχαρη, νιφάδες πιπεριού, μπαχάρι, φύλλα δάφνης, κάρδαμο, κανέλα, γαρύφαλλα, κόλιανδρο, σκόρδο, τζίντζερ, σπόρους μουστάρδας, κόκκους πιπεριού και πολλά άλλα.
  6. Οι πιπεριές τουρσί. Ρίξτε την καυτή άλμη στο βάζο, πάνω από τις πιπεριές και σφραγίστε με ένα σφιχτό καπάκι. Αφήστε να κρυώσει και μετά στο ψυγείο για συντήρηση.
  7. Περιμένετε μια εβδομάδα. Αφήστε τις πιπεριές να "ψηθούν" μερικές εβδομάδες πριν από τη χρήση, ώστε να μπορούν να πάρουν όλες τις γεύσεις, αν και μπορείτε να τις δοκιμάσετε και αμέσως.
  8. Είναι καλύτερο να περιμένετε να αφήσετε τις γεύσεις να αναπτυχθούν. Εάν δεν μπορείτε να περιμένετε, περιμένετε τουλάχιστον 24 ώρες και, στη συνέχεια, απολαύστε τις.
